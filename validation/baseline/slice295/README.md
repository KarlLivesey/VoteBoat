Public SessionDrainStatus, TransportDrainStatus and PeerDrainStatus expose

provider), never proof that work is drained. Native framed status preserves
original send/receive slots; native QUIC exposes its original monotonic deadline,
close-start flag and actual Quinn drain predicate. Guarded inspection checks
validity but does not revoke; normal public polling still enforces revocation.
