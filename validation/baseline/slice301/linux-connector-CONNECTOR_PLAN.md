# Shared connector assertion slice

Purpose: close the one reusable assertion gap in PROVIDER_EXIT_REVIEW; advance the finite selected-provider acceptance evidence, not add a provider capability. Dependencies: public PeerConnector request/ticket/usage/time/budget contract, existing independent HostConnector and existing native TCP fixture. Ownership: only tests/connect.rs registration/wrapper and new tests/connect/conformance.rs; no production/shared-doc/dependency changes.

Schema: accept the exact original local/peer/store/session/generation ticket at supplied MonoTime10, deadline90. The real native listener has no connecting client, so its accepted Accept request cannot race to successful authentication. Zero visits/socket/completions advances only supplied time to11, leaves accepted ownership and deadline. Wrong-ticket cancel, oversized poll budget, backward-time poll and submission refuse without changing usage/deadline. Rejected Dial requests retain every original owned field, including endpoint. Close stops admission and turns accepted attempt into retained cancellation; zero-completion polling still owns its credit. New post-close request returns whole owned request with Closed. A bounded single terminal poll consumes only original ticket with Cancelled, releases credit and reaches drained; repeated polls are empty. Existing native finish closes listener and joins its own dialer. No local-send/authentication result becomes consensus evidence; no timeout or elapsed-time success is used.

Acceptance: same generic runner passes host and native fixtures; full connect target passes relevant all/default/core/native profiles; formatting and strict Clippy zero with isolated CARGO_TARGET_DIR=target/divide-membership/build. Parent integrates and provides macOS/current-repository qualification. Failures, fixes and terminal commands remain under target/divide-membership. No commits or pushes from this agent.
