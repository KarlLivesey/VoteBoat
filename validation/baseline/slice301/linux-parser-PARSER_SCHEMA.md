# Bounded public parser/recovery mutation campaign

Purpose: advance chapter11 functional parser fuzz gate across WAL/batch recovery, RPC decoding, snapshot manifest/codec and routing boundaries. No new dependencies, security claim, production edits or shared-doc edits. Tests only use public APIs and independently retained expected fixtures.

Data/API: new tests/parser_campaign.rs and owned child modules. Shared deterministic generator uses eight fixed nonzero seeds,192 cases per corpus, explicit mode selected by case modulo8: original, single-bit corruption, truncation, bounded insertion, bounded deletion, bounded overwrite, hostile length/count overwrite, bounded random blob. Input maximum is original fixture+32 bytes. Family-specific checksum repair on overwrite/length cases drives inner parsers rather than stopping every case at CRC. Independent CRC32C checked against standard123456789 vector; repair is test mutation plumbing, not authentication.

Oracles: original input must exactly roundtrip/recover; successful arbitrary mutated parse must validate through public shape constructors/re-encoding and stay within configured message/entry/application/route budgets. Valid changes may accept; no blanket demand every mutation refuses. Single-bit damage/truncation to complete checksummed codec frames must refuse; routing has no checksum and valid field changes may accept. Each case is caught solely to annotate any panic with family/seed/case/mode/actual bytes, then fails the test. Decoder receives immutable borrowed input and must not mutate it. Keep accepted/refused/checksum-repaired counts, assert actual positive/negative activity and print reproducible campaign totals.

WAL/batch: real NativeLogCodec Create and Update fixtures plus NativeLogStore<ModelIo> generated durable journal/manifest. Decode mutated batches under small valid LogLimits; accepted batches re-encode/decode equivalently with counts bounded. Mutate acknowledged journal or native journal manifest separately; unmodified recovers exact original GroupLog/fresh session. Unrepaired damaged acknowledged prefixes refuse; generated extra interrupted tails may refuse or recover exactly original acknowledged state, never create partial acknowledged application. Deep rechecksummed batch parsing is separate from truthful provider recovery; this is not cryptographic corruption detection.

RPC: real NativeWireCodec selected formats1 and8, a multiplexed Vote/ReadProbe/Append/ReadAck corpus and snapshot-bearing frame. Mutate full frames/header fields with both raw and resealed inputs. Accepted decoding must preserve authenticated scope, satisfy count/bounded payload limits and public encode/decode equivalence. Wrong external scope always refuses original frames. Success is format consistency only, not authority or authentication.

Snapshot: real NativeSnapshotCodec application+metadata fixture; stage/publish through actual NativeSnapshotStore over independent bounded two-slot SnapshotIo to obtain actual manifest bytes. Mutate codec image and published root separately. Accepted image metadata validates, re-encode/decode equivalently, retained application size stays bounded. Actual snapshot-store manifest recovery must preserve exact image/identity on accepted roots; damaged checksummed roots refuse, with rechecksummed hostile descriptor/count/identity shapes probing read limits. Every supplied slot read is bounded and missing/oversized slot refuses. No disk rollback/state fabrication after failed recovery.

Routing: real public DirectoryCommand encode/decode around checked delegated/partitioned ResponsibilityManifest, including edge bucket0/256 and adjacent ranges. Arbitrary mutations plus targeted encoded count/range changes exercise route-length/count/coverage validation. Accepted decoded manifest reconstructs through ResponsibilityManifest::new and re-encodes/decode equivalently; routes bounded by MAX_MANIFEST_ROUTES, exact disjoint coverage of original decoded scope. Invalid gaps/overlaps/zero/inverted/out-of-domain boundaries cannot become accepted route authority. This covers the selected manifest publication decoder, not every lifecycle command or recursive resolver schedule.

Ownership/cleanup: each recovery case gets fresh independent in-memory device data and drops recovered provider; failed parser results return no usable partial batch/image/manifest. No background processes or shared resource owners. Feature-native families compile behind cfg; routing/generator run in core-only builds. Files precede module declarations to keep concurrent root builds valid.

Acceptance: focused generated campaigns pass all features and core-only with isolated CARGO_TARGET_DIR=target/divide-conformance/parser-build; formatting and strict all-target/all-feature Clippy clean. Parent integrates authoritative macro/mini/schema ledger and frozen Linux/macOS four-profile qualification. Counts prove a bounded seeded mutation run, not unbounded coverage-guided fuzzing or exhaustive allocation safety. No custom unsafe allocator hooks: output sizes/public budgets and bounded read limits are checked, not process RSS or every allocator failure.
