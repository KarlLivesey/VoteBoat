logical voters. P9 performance and P10 security remain later separate phases.

## Implemented contracts and evidence limits

One immutable spec names a coordinator, two canonical participants, account
references, amount and ten phase operation IDs. Construction checks compatible
profile/role/incarnation, original opening accounts and full lifetime capacity
across 1..64 Nodes with selective group inventories. A fresh host-allocated
TransferDriverGeneration is required for every attachment under the same RuntimeOwner.
The driver consumes the exclusively borrowed Nodes' client/read streams.

Actual Start, Prepare, Decide, ApplyDecision, AppliedAll, Release and Finish
results supply canonical first indices and immutable retry bytes. Resume reads
the original coordinator state through its current quorum, then reconstructs
the remaining monotone work. Unknown, timeout, cancellation, admission failure
or absent status never selects Abort or unlocks accounts. Business refusal is a
retained application decision. Node/provider failures stop new phase production,
retain original rejected outputs, and allow bounded cleanup visits.

Driver credits remain owned through exported completion consumption. Drain also
requires actual Node client/read reservations to drain. Drop performs no I/O,
compensation or host shutdown. The standalone embedding selects one physical
voter hosting all three groups; the native histories use three physical replicas
and actual TCP/TLS or QUIC. No second storage owner or hidden runtime is added.

Seven private negative controls consume real opaque Node outputs against a wrong
retained Node, ticket, command, operation or query and reject before dependent
work. Public host fixtures use actual generic Nodes with downstream providers in
core-only builds. Native histories cover commit/reverse direction, exact retries,
durable funds/contention refusal, absent Abort, lifetime capacity, original lost
observations, old prepared checkpoint plus committed decision/apply suffix,
remaining phase resume, fresh-generation ownership refusal and joined cleanup.

Leader replacement is graceful retirement/join/reopen with a surviving majority.
Quorum loss retains two actual Node owners without polling; the survivor cannot
obtain a fresh quorum read, returns Unknown after stopping observations, preserves
the original locks/state, then resumes after actual polling repair. These are not
physical network partition or abrupt process/power-crash histories. The example
recovery control observes accepted Start, aborts the actual Node, drains its
recovery ownership, joins selected providers and cold reopens retained files; it
does not establish that the accepted Start was already Applied.

The CLI create/retry/resume histories return original finish index5 and balances
983/17 with actual worker joins on both hosts. Missing ID99 reports
Unknown(NoRetainedStart), exits1 after cleanup and preserves files. Independent
[review](DRIVER_REVIEW.md) found the example's early return on RecoveryRequired;
the focused actual recovery path fixes it. Review found no remaining concrete
driver blocker under the explicit trusted-provider/generation contract. Initial
fixture capacity and example wire-version failures, focused fixes and outputs
remain retained. No lint threshold, dependency or Raft rule was weakened.
