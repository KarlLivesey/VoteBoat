No attribution of prior singleton observations is claimed. Root separately owns per-Core BatchLimits and downstream broad/crash qualification.

All other control events, including any hidden behind a routine head, and all background work remain boundaries. No received acknowledgement is accepted by this inspection. Batch count is the minimum of remaining visit items, caller output budget, per-Core max_proposal_entries, entry capacity and byte budgets. The class ORDER and cursor do not change: a selected Data turn becomes one bounded batch quantum. This preserves class-turn selection, not a strict per-command 2:1 weighted event ratio.

Existing queued read, untracked input, timer-bearing proposal, failure-prefix and protected-work boundaries remain intact. No timers or arrival delay are added.
