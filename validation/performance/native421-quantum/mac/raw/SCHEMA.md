visit improves actual quorum-durable capacity. A single exact1091610 native
executable per host runs requested quantums16/32/64. Every other setting is held
constant. Linux and M2Max are separate within-host comparisons; never normalize
cross-host throughput into a software speedup.

API/data: reuse the completed419 native measurement driver and its per-original,
CSV, journal and source/artifact guard logic. Replace before/after source variants
with explicit policy variants on one source/library/executable. Reports retain
requested/effective ready quantum, existing Core64, byte1MiB/time2ms, actual proposal
width distributions, physical append/sync/publication counts and p99. Closed-loop
256 originals plus64 warmup, windows32/1, TCP/TLS and QUIC, one group/three replicas,

short diagnostic; no sustained floor/headroom/hot-cold/maintenance acceptance.

Sequence/ownership: complete fresh frozen Linux/native and Mac/native artifact
proofs first. Snapshot exact source/artifact identities before and after campaign.
No builds/tests/copies on the host during timings. Rotate all three policy orders
across three trials for each protocol/window. Fresh directory percase, same files,
raw stdout/stderr/exit and original command retained. Each success must reopen the
journal, reconstruct Counter320, verify duplicate receipts for the first and last original IDs without
changing the recovered value, then join workers.

Failure/cleanup: no source modification or engine setting change midcampaign.
Keep original authoritative job handle/PID; observation timeout is not workload
failure. A failed measurement keeps partial records and excludes the full campaign
from a capacity conclusion; do not drop a slow successful trial. Preserve existing
finite internal deadlines and join cleanup. Agent Mac422423 qualification must be
terminal before remote timing; Linux fresh native compilation must be terminal
before local timing. Root reviews adapted driver diff before execution.

Acceptance:36 successful cases perhost (2protocols×2windows×3trials×3quantums),
all source/library/executable/profile/setting/count/recovery/journal guards, full
