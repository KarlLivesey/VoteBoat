## Schema recorded before source edits

Public StateMachine adds apply_batch_into and apply_entries_into returning Result<(), ApplicationError>, replacing a caller Vec. Defaults clear on entry then invoke their respective old owned method exactly once. The entries default honors a custom EntryRange override; no recursion or receipt Clone/Copy/Default bounds. Rust exclusive borrows protect outstanding output; a caller can take the Vec to retain it. The same call's partial receipts are cleared on Err; generic state progress still follows its existing contract/fatal host fencing, not rollback.

Counter's existing staged novel map, pre-counting, value/applied staging and commit loop become one internal implementation receiving output. Owned methods allocate local output and use that path. The new entries override uses existing contiguous adaptation; no second optimisation. Late invalid/index/dedup failures clear output and preserve original state. Scratch is external to checkpoints/dedup.

Matched Noop keeps every index/empty-command validation and every receipt on all three applications, with only whole-interval frontier commit. Both Actor paths (canonical borrowed completion and FIFO owned Effect::Committed) call public into methods. One Vec belongs to each concrete Actor, empty between intervals. Application completes before first leader reply. Drain drops remaining output on client/missing result failure, keeping already advanced application/pending/fatal behavior. Followers produce the complete output before clearing. Snapshot/recovery/other groups own no scratch from this Actor.

Retained ceiling: existing validated clients * 4 + 1 original bound, safe saturating arithmetic capped at isize::MAX / size_of::<OperationId>() so byte multiplication stays finite. Count capacity, including Vec geometric spare, rather than length. Retained bytes <= ceiling * size_of::<OperationId>(); no nested receipt allocations for OperationId. Legal oversized intervals may allocate temporarily and are consumed normally; afterward capacity above ceiling is dropped. No new input rejection, batching reduction, config knob or generic cache abstraction. Public callers account their own Vec including spare capacity. BoundedStateMachine receipt budget and native routers remain unchanged.

No new consensus effect/watermark/generation/restart state. Pending/installer/quorum/wire/core pipelines unchanged. No root/ancestor operation on child writes. No replay, early success, fictitious rollback or follower elision.

## Data/API and state schema before edits

Add a public caller-owned output seam to StateMachine, e.g. apply_batch_into(entries, &mut Vec<Self::Receipt>) and apply_entries_into(EntryRange, &mut Vec<Self::Receipt>) returning Result<(), ApplicationError>. Final names may follow existing conventions. These are ordinary application operations, no consensus/durability token, callback or altered evidence. They REPLACE the output of one call; clear any old contents on entry, and expose no partial receipts on Err. Caller retains output capacity/ownership and must finish consuming/taking a previous result before reusing its buffer. Owned-return apply_batch/apply_entries remain functional. Default new methods invoke the respective existing owned method exactly once, honoring custom apply_entries overrides and fully functional third-party/composite applications. They must not recurse through each other. No Receipt: Clone/Copy/Default requirement or invented success for unsupported providers.

Do not additionally fuse passes, change dedup maps, remove Counter pre-counting, alter result semantics or optimise unrelated lifecycle/storage. Old owned Counter methods retain their original behavior and fully working path. Retained caller capacity is external scratch, not Counter snapshot/dedup state.

## Ownership, budgets, cleanup, restart

Buffer belongs to its concrete host/application actor, never global/threadlocal or shared across groups. No hidden provider/thread/allocator. If an otherwise legal output requires a bigger temporary Vec, consume it normally and discard excess capacity afterward; do not reject legal input, reduce batches or retain unbounded high-water memory. Public callers own and account their Vec; new optional seam does not waive BoundedStateMachine receipt-budget/spare-capacity accounting. Existing native bounded routers stay on their current functional path unless a separate necessity is demonstrated; do NOT migrate or change their accounting in this slice.

Rust exclusive borrows preserve outstanding output lifetime. Taking/retaining an owned prior output must prevent it from being overwritten (caller may take its Vec and use a different buffer). Snapshots/checkpoints/restore do not encode scratch or create new generations. Dropping one group drops only its buffer; other host/group buffers remain valid. Accepted application is never rolled back because a client wait was canceled.
